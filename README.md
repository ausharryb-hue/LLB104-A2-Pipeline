# LLB104 — Essay Assignment Pipeline

An interactive family-tree flow diagram for structuring a critical essay. Start with your central argument and branch out into areas and sub-points.

## Getting Started

```bash
npm install
npm run dev
```

## How to Use

- **Double-click** any node to edit its text
- Click **+ Branch** on the central argument to add a main area
- Click **+ Point** on an area to add a sub-point
- Click the **status badge** on a point to cycle: To Do → In Progress → Done
- Click **✕** to delete a node (and all its children)
- Click **Auto Layout** to re-run the top-down tree layout
- Your tree is saved automatically in `localStorage`
